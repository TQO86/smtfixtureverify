# SMT Fixture Verify 4.9

Aplicativo estático: https://tqo86.github.io/smtfixtureverify/

Os checkboxes X e Y acima de Calcular e marcar centro permitem atualizar apenas a coordenada global escolhida da marcação de centro. Ambos marcados mantêm o cálculo completo da caixa da seleção. Sem eixo marcado, o cálculo fica desabilitado.

Funciona com traços 2D e arestas 3D. Os projetos .sfv preservam os centros, arquivos originais e transformações; Ctrl+Z restaura a marcação anterior.

GitHub Pages publica a raiz da branch main. Os projetos são processados localmente no navegador.
